 New Target Scanner Features:
1. URL/Domain Scanning:

DNS Lookup - IP address, reverse DNS, all IPs, aliases
HTTP Headers - Server info, technologies, security headers
SSL/TLS Information - Certificate details, cipher suites, expiration dates
Common Port Check - Tests popular services (FTP, SSH, HTTP, HTTPS, MySQL, etc.)

2. IP Address Scanning:

Reverse DNS Lookup - Find associated hostnames
Port Discovery - Scan common ports for services
Service Identification - Identifies running services

3. Port Scanning:

Custom Range - Scan any port range (1-65535)
Real-time Updates - Shows open ports as they're discovered
Service Detection - Identifies services on open ports (SSH, HTTP, MySQL, RDP, etc.)
Progress Tracking - Visual feedback during scan

4. Scan Options:

Toggle DNS lookup, WHOIS, HTTP headers, SSL/TLS info
Customizable port ranges
Timeout configurations
Export scan results

5. Features:

Multi-threaded scanning (doesn't freeze UI)
Color-coded results (errors in red, success in green)
Service name database (20+ common services)
Export capabilities
Progress bar

Example Usage:

Scan a website: Enter google.com, select "URL/Domain", click "Start Scan"
Scan an IP: Enter 8.8.8.8, select "IP Address", click "Start Scan"
Port scan: Enter target, select "Port Scan", set range (e.g., 20-1024), click "Start Scan"

The tool now provides both passive reconnaissance (log analysis) and active reconnaissance (target scanning) capabilities! 🔍
